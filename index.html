A linked set of visual mental models, animated walkthroughs, C# templates, pattern-recognition guides, pitfalls, and active-recall prompts. The pages emphasize reusable archetypes behind common interview and LeetCode-style problems.

Recommended method: predict each animation step before clicking, state the invariant aloud, then implement the C# template from memory. Pattern recognition matters more than memorizing individual solutions.

A practical study route

Day 1

Arrays → Strings → Hash Tables. Learn lookup, counting, two pointers, windows, and prefix sums.

Day 2

Linked Lists → Stacks → Queues. Learn pointer state, unfinished work, monotonic structures, and BFS.

Day 3

Trees → Heaps. Practice recursive contracts, traversal order, top-k, and scheduling.

Day 4

Graphs → Union-Find → Grids. Practice traversal, shortest paths, dependencies, and connectivity.

Day 5

Tries → Intervals → Range Query Trees. Cover specialized high-signal patterns, then revisit weak areas.

Day 6

AI Agents. Trace the control loop, then explain RAG, MCP, identity, sandbox, and production safety as separate trust boundaries.
